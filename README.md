# 字帖 — 对话式汉字字帖生成器

一句话生成田字格/米字格练字帖 PDF,同步部编版(统编版)小学语文教材。家长/老师说"一年级上册第五课"或"今晚作业默写第8课词语",直接拿到可打印的字帖 PDF。

## 功能特性

- **一句话生成** — 说"一年级上册第五课 米字格"即可,不用翻目录、不用查生字表
- **教材同步** — 内置部编版 12 册教材生字数据(5520 字次),识字表 + 写字表,自动匹配
- **任意文本练字** — 粘贴一段话(古诗/作文/文章),自动提取汉字、标注拼音笔画、生成字帖
- **提取未学字** — 粘贴文章 + 说年级,自动挑出"孩子还没学过的字"生成字帖(预习/复习神器)
- **离线可用** — 规则解析器完全本地运行,不依赖网络与 API key
- **双解析架构** — 规则先行(免费/快/离线),LLM 只处理规则解析失败的输入
- **矢量 PDF** — pdf-lib 生成矢量字帖,任意缩放打印依然清晰
- **移动端友好** — Vue3 聊天式界面,手机上一样好用

## 快速开始

### CLI(两条命令)

```bash
cd engine
npm install
npx tsx src/cli.ts "一年级上册第五课 米字格"
```

PDF 输出到 `engine/out/`。加 `--no-llm` 可强制禁用 LLM(纯规则解析)。

### Web(三步)

```bash
cd web
npm install
npm run build        # 产物在 web/dist/,由 engine 的 server 托管
```

```bash
cd engine
npx tsx src/server.ts   # 启动 http://127.0.0.1:8787
```

开发模式:`cd web && npm run dev`(Vite 自带 proxy,`/api` 转发到 8787)。

### HTTP API

```
POST /api/copybook
Content-Type: application/json
{"text":"一年级上册第五课"}
```

响应 `{"ok":true,"source":"规则","parse":{...},"lessonInfo":{...},"pdfBase64":"..."}`。

### LLM 兜底(可选)

自由表达(如"今晚作业默写第8课词语")由 LLM 解析,需要环境变量:

```bash
export OPENCODE_GO_API_KEY=your_key   # PowerShell: $env:OPENCODE_GO_API_KEY="your_key"
```

- 网关:OpenAI 兼容接口 `https://opencode.ai/zen/go/v1`,模型 `deepseek-v4-flash`
- **未设置 key 时自动降级为纯规则解析**,CLI 加 `--no-llm` 或请求体 `{"llm":false}` 可显式禁用

## 使用示例

| 输入 | 解析 | 输出 |
|---|---|---|
| 一年级上册第五课 米字格 | 规则 | 一年级上册第5课,3 字(虫/云/山),米字格 PDF |
| 一上5课 | 规则 | 同上(简称也支持) |
| 二年级下册识字5 | 规则 | 识字表第5课,9 字,田字格 PDF |
| 六年级上册第3课 | 规则 | 六年级无识字表,自动用写字表,3 字 |
| 春眠不觉晓 米字格 | 文本模式 | 任意文本 → 提取 5 字(春眠不觉晓),米字格 PDF |
| 春眠不觉晓 二年级 | 未学字模式 | 已学至二年级,挑出未学字(眠/晓)生成字帖 |
| 全册 不要拼音 | 规则 → LLM 兜底 | 全册会写字,无拼音;缺省册别时 LLM 默认一年级上册(需 API key) |
| 今晚作业默写第8课词语 | 规则失败 → LLM 兜底 | 一年级上册第8课会写字(需 API key) |
| 胡说八道 | 规则失败 → LLM 失败 | 报错:`无法识别的指令: 胡说八道` |

网格:米字格 / 田字格 / 无格(方格);开关:拼音、笔画数(如"不要拼音""不要笔画")。

## 架构说明

```
┌────────────────────────────────────────────────────────┐
│            前端(Vue3 + Vite,聊天式输入)                  │
│        "一年级上册第五课 米字格"                          │
└──────────────────────┬─────────────────────────────────┘
                       │ POST /api/copybook
┌──────────────────────▼─────────────────────────────────┐
│        HTTP API(零框架,Node 原生 http,无状态)             │
└────────────┬──────────────────────────────┬────────────┘
             │ 规则解析失败时                  │ 兜底
             ▼                              ▼
┌────────────────────────┐       ┌────────────────────────┐
│   规则解析器 parse.ts    │       │   LLM 解析 llm.ts       │
│ "一上5课"→结构化参数      │ ───►  │ "今晚作业默写第8课词语"   │
│ (免费/快/离线)           │       │ (可选,需 API key)       │
└────────────────────────┘       └────────────────────────┘
             │ 统一结构化参数(册/课/格/拼音/笔画)
             ▼
┌────────────────────────────────────────────────────────┐
│      数据层 + 字帖引擎 index.ts                          │
│  data/final/ 12 册 JSON(5520 字次)→ 选中字 → 布局计算     │
└──────────────────────┬─────────────────────────────────┘
                       │
┌──────────────────────▼─────────────────────────────────┐
│   PDF 生成(pdf-lib 矢量)                                 │
│   演示春风楷 + DejaVu Sans(拼音声调)                      │
│   田字格 / 米字格 / 无格 · 拼音 / 笔画开关                 │
└────────────────────────────────────────────────────────┘
```

**设计理念:规则先行,LLM 兜底。** 常见指令免费、快速、离线可用;只有规则解析不了的自由表达才交给 LLM,在低成本的前提下尽量理解用户。

## 数据说明

- **覆盖**:部编版 12 册(一上 ~ 六下),5520 字次,每册含识字表(会认)+ 写字表(会写)
- **字段**:每字含 `char`(汉字)、`pinyin`(拼音,带声调)、`strokes`(笔画数)、`radical`(部首)、`structure`(结构)
- **来源**:教材 PDF(TapXWorld/ChinaTextbook 的 `小学/语文/统编版/义务教育教科书·语文X年级X册.pdf`)→ `pdftotext -layout` + 坐标解析提取,cnchar 补全汉字属性
- **协议**:
  - 教材生字为事实数据,据公开教材提取整理
  - cnchar:Apache-2.0
  - 演示春风楷:OFL(免费商用);DejaVu Sans:自由字体
  - 详细提取方法见 [data/README.md](data/README.md)

感谢 [TapXWorld/ChinaTextbook](https://github.com/TapXWorld/ChinaTextbook) 提供的教材 PDF。
